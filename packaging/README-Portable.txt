PDFTextEditor 便携版  @VERSION@

【怎么用】
1. 把整个 PDFTextEditor 文件夹解压到任意位置（桌面、D 盘、U 盘都行）。
2. 双击 PDFTextEditor.exe 打开，直接就能用。
3. 不需要安装，不需要管理员权限，不需要装 Python。

【重要】
不要放在 C:\Program Files 这类需要管理员权限的目录，
否则字体缓存可能写不进去。放在桌面或其他自己的目录最省事。

【改动效果】
· 选中左边预览里的文字、在「替换」里填新内容，右边会立刻显示改后效果，
  不用先点「添加到清单」；点「添加到清单」才真正记进规则。
· 想一次改一整句：在文字上按住左键拖一个框再松手（拖动不足 3 像素算单击）。
  网页 / Markdown 转出来的 PDF 常常"一个字一个片段"，点选只能改一个字，
  框选就能一次圈一整句；Word 类的 PDF 一行一个片段，框选就是选整行。
  框选目前只支持一行内，跨行会提示并只取你按下时所在的那一行。
· 文字颜色默认跟随原文（灰字、红字不会被改成黑色）；也可以点色块调色，
  或用「取色器」直接在页面上点一下取色。
· 字号按原文精确取值；伪加粗描边默认关闭，需要时在「高级」里打开。
· 替换文字里如果有当前字体没有的字形（例如把英文片段改成中文），程序会逐字改用
  包含该字形的字体（默认宋体优先），并在「替换」行和日志里说明，不会画成方框。

【如果「原文」是乱码】
有些 PDF 的文字层抽出来是乱码（字体没带 Unicode 映射）。这时直接在「原文」框里
改成正确的文字再替换即可 —— 替换位置是按原文位置走的，改文字不影响位置。

【字体是"内嵌字形"（Type3）】
网页 / Markdown 转出来的 PDF 常见：每个字的字形都内嵌在 PDF 里，系统里根本没有
对应字体文件。这种情况程序不会弹"缺少字体"，而是用中文字体近似，并在
「已识别」那一行说明；想换字体可以在「字体」下拉里自己挑。

【如果提示"缺少字体"】
程序会自动读 PDF 里的字体名，在系统字体里找对应的那个。找不到时会弹一个小窗
告诉你是哪个字体 —— 把字体文件（.ttf / .otf）放进本文件夹的：

    data\fonts\

然后回到窗口重新点一下那段文字即可。

· 不需要装进 Windows 字体文件夹（那个要管理员权限），也不用"安装"。
· 字体放这里只对本软件生效，不会影响系统其它程序。

【卸载】
直接删除整个 PDFTextEditor 文件夹即可，不留任何残留。

【文件夹里有什么】
PDFTextEditor.exe   程序本体
_internal\          运行库（不要删、不要改）
portable.flag       便携版标记（缓存会写在本文件夹内）
data\               缓存与设置（字体缓存、主题偏好等），可随时删除
  data\fonts\       放自己下载的字体（可选）
README-Portable.txt 本文件（使用说明）

【首次运行提示】
本程序未做数字签名，Windows 可能弹出「Windows 已保护你的电脑」，
点「更多信息」→「仍要运行」即可。

【系统要求】
64 位 Windows 10 及以上
